# TCSS 490 Portfolio

A small static portfolio for TCSS 490 (Generative AI and Software Development, Autumn 2026), built with plain HTML, CSS and JavaScript and hosted on GitHub Pages at https://trentenmuw.github.io. It has one card for each of the quarter's five artifacts: the first card is this site, and the rest start as ideas and get filled in as each artifact is finished. `LOG.md` records what I asked the AI for and what changed.

## How to update a card

1. Open `artifacts.js`.
2. Find the artifact's object.
3. Set `status: "complete"` and fill in `link`, `description`, and `reflection`.
4. Commit and push. The site updates in about a minute.
